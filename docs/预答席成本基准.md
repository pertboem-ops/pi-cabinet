# 预答席成本基准（启用前置④ · 2026-10-13）

> 依 2120 场议定书 P4④ 与重启设计 v3 §四-4 执行：**非正式场次、不入任何议事账**。
> 本测量回答的问题是"预答席单次调用的价格"，供用户知情后决定是否自愿承受。

## 测量条件

- 路由：zai-coding-cn/glm-5.3 · high（与正方钉扎同档——"异源同档"配置的代表档；
  家族选择与强度无关，仅测同档席位的一般成本形态）
- 议题：裸议题（与预答席谱系零关联的独立决策问题："写作角色包是否增设排版官
  席位"），无归档材料、无席位名单——模拟设计 v3 §二-1 的最小输入形态
- 形态：单次委派，run_in_background，产出 ≤1200 字完整论证

## 结果（接口口径粗估，如实注明不可观测部分）

| 项 | 数值 | 口径 |
|----|------|------|
| 产出体量 | ≈1050 字正文（含结论/论证链/风险/落地步骤/双点） | 实测字数 |
| token 粗估 | 简报出 ≈1.2K 字 + 报告入 ≈1.1K 字 ≈ **2.5–3.5K token** | 接口口径（简报出+报告入）；子智能体内部读取不可观测，如实注明 |
| 延迟 | 自报主观耗时 ≈6 分钟；壁钟不可精测（派发与回报分属宿主回合） | 转述级+不可观测声明 |
| 调用计数 | 1 次委派 | 精确 |

## 结论

- **预答席单次成本 ≈ 一席 R1 量级**：`tiers.json` 预答轨 `tokens: 3500` 名义初值
  与实测粗估同量级，采纳为默认值（启用后逐场以实际 cost 校准）；
- **延迟为分钟级串行前缀**：R1 前多出的一次顶档推理是真实等待成本，属用户
  自愿承受项（反方 Q5 知情条件自此满足）；
- high 档位的长推理占比高，token 名义值偏保守是正确方向（宁低不高——超支
  走 token 软轨如实记账，不触执法轨）。
